# رادار أمان

نظام لرصد إعلانات الاحتيال الإلكتروني بالذكاء الاصطناعي.

## الصفحات
- `/` صفحة الفحص العامة (فحص سريع + فحص معمّق تلقائي)
- `/admin` لوحة الضابط (بكلمة سر)

## المتغيرات المطلوبة في Vercel (Environment Variables)
- `ANTHROPIC_API_KEY` مفتاح Anthropic API
- `ADMIN_PASSWORD` كلمة سر لوحة الضابط
- قاعدة البيانات: أضف Upstash Redis من تبويب Storage (يضيف متغيراته تلقائيًا)

## متغيرات اختيارية
- `DAILY_SCAN_LIMIT` الحد اليومي للفحص السريع (افتراضي 150)
- `DAILY_DEEP_LIMIT` الحد اليومي للفحص المعمّق (افتراضي 40)
- `INGEST_KEY` مفتاح بوابة الاستقبال `/api/ingest` لمصادر الرصد الآلي مستقبلًا
- `CLAUDE_MODEL` نموذج الذكاء الاصطناعي (افتراضي claude-sonnet-5-5)
